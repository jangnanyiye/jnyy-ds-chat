# DS Chat 使用手册

## 对话与模型

- 右上角切换 **V4-Pro** 或 **V4.1 Flash**。
- 输入框旁的「深度思考」控制本轮是否开启推理；开启后回答上方会显示可折叠思维链。
- 「联网搜索」会自动切换到 V4.1 Flash，并在回答底部展示参考来源。
- 有文件/图片附件时同样会使用 V4.1 Flash。
- 生成过程中可以停止；停止或服务重启会标记为已停止/已中断，不会丢失已有内容。

## 文件与图片

- 支持文件选择器、拖拽到输入框、直接粘贴三种方式。
- 图片会直接送给模型识别；PDF / Word / PPT 默认只提取文字，文档内嵌图片不会解析。
- 单条消息最多 6 个附件。
- 限制：图片 64 MB、文档 100 MB、文本/表格/电子书 32 MB。
- 可以只发送图片/文件，不必额外输入文字。

## 分支

- 编辑用户消息或重新生成时，旧回答不会被删除，而是生成一个新分支。
- 消息下方用 `< 1/2 >` 切换版本。
- 搜索命中旧分支时，点击结果会自动切到对应分支。

## 系统提示词

- 在「设置 → 对话 → 管理提示词库」中创建、编辑、删除提示词。
- 新对话开始前，在顶栏设置按钮中为对话选择提示词；对话开始后锁定。
- 对话会保存一份提示词快照。之后修改或删除提示词库里的条目，不会改变已经开始的对话。
- 提示词库的删除操作不会影响已有对话，可以放心清理不再使用的条目。

## 单轮对话

- 单轮模式只在对话开始前设置，开始后锁定。
- 开启后，每轮只发送：当前问题 + 系统提示词 + 手动引用。
- 历史消息仍会保留在对话、分支和搜索中，只是不发送给模型。
- 适合同类独立问题，能减少上下文 token 和注意力干扰。

## 引用

- 任意用户消息或助手回答下方都有「引用」按钮。
- 可选择多条（最多 8 条），发送前可在输入框上方移除。
- 引用会作为「手动引用的历史上下文」注入本轮问题，特别适合在单轮对话中追问。
- 引用不能单独发送，必须同时输入问题或添加附件。
- 引用保存的是文本快照，不包含被引用消息的附件。

## 搜索与分页

- `Ctrl+K` 打开全局搜索，搜索标题和所有分支的消息。
- 对话列表和搜索结果按最近更新时间从近到远分页加载。
- 默认每次加载 20 条；可以在「设置 → 系统 → 搜索步进」改为 10 / 20 / 30 / 50。
- 点击列表底部「加载更多」继续读取下一批。

## 设置

侧栏底部进入「设置」：

- **主题**：深色模式；锁定深色模式。未锁定时每次加载优先跟随系统设置，避免深色环境闪白。
- **对话**：显示/隐藏每轮 token、助手头像和名称、顶部对话名称；开始对话时显示系统提示词。
- **新对话默认设置**：默认提示词、默认单轮模式。
- **系统**：搜索步进、退出登录。
- **关于**：内置手册。

## PWA 与移动端

- Android Chrome / Edge 可通过浏览器菜单安装到主屏幕。
- 再次启动优先复用已打开的窗口。
- 适配状态栏、刘海和底部手势条；亮色状态栏为白色，暗色为深色背景。
- 移动端不自动聚焦输入框，避免生成结束后反复弹出键盘。
- 助手头像和名称位于正文上方，窄屏下正文占满宽度。

## 数据与限制

- 对话、分支、附件元数据和提示词快照都保存在服务器 SQLite。
- 附件文件保存在服务器的 `UPLOAD_DIR`。
- 单用户服务，没有注册、找回密码、知识库或对外 OpenAI API。
